# State-Space Truncation for Matching Systems

Python code for the numerical example in the final part of **State space truncation and admission control for matching systems** (NETGCOOP 2026).

`PawTruncation2.py` uses exact rational arithmetic and dynamic programming to compute truncated stationary quantities and mean queue lengths for the paw-graph example.

```bash
python PawTruncation2.py
```

This repository currently contains the paper's specific example; fuller documentation will follow.
